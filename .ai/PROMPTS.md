# Representative AI prompts used during development

The goal is to show iterative use of AI rather than hiding the development process.

## Prompt 1 — requirements

Read the KangaSys take-home requirements and turn them into:
- mandatory features
- optional features
- ambiguous decisions
- a minimal implementation plan

Do not write code yet.

## Prompt 2 — data model

Given devices, readings, and threshold alerts, propose a small relational schema.
Pay special attention to the supplied sample where two temperature sensors have different safe ranges.

## Prompt 3 — backend

Implement the API incrementally:
1. device CRUD
2. reading ingestion
3. threshold alert creation
4. alert resolution

Keep business logic separate from HTTP routes.

## Prompt 4 — tests

Suggest tests that target business risk rather than chasing 100% coverage.
Include normal values, below-minimum values, above-maximum values, inactive devices, invalid units, filtering, and alert resolution.

## Prompt 5 — review

Review the implementation against the original assignment.
Look for:
- missing requirements
- bad validation
- poor separation of concerns
- assumptions that are not documented
- likely bugs

## Prompt 6 — AI correction log

If generated code is incorrect, record:
1. what was wrong
2. why it was wrong
3. what was changed
4. how the change was verified

This file is intentionally a prompt record, not a claim that every line was generated by AI.
